## 📋 Project Overview

BASML Cotton & Yarn Dashboard is a cutting-edge web application designed for traders, farmers, textile manufacturers, and market analysts to monitor real-time cotton and yarn prices, analyze global and Indian market trends, and forecast future price movements with AI-powered predictive analytics.

### 🎯 Purpose
- **Real-time Price Tracking**: Monitor cotton and yarn price movements across global and Indian markets
- **Market Analysis**: Understand market trends, supply-demand dynamics, and seasonal patterns
- **Predictive Forecasting**: Leverage AI to forecast future price movements for informed decision-making
- **Global & Indian Market Insights**: Comprehensive coverage of major cotton and yarn exchanges

## 🚀 Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn package manager
- Modern web browser

### Installation

```bash
# Clone the repository
git clone https://github.com/ramanan081-hub/basml-cotton-yarn-dashboard.git

# Navigate to project directory
cd basml-cotton-yarn-dashboard

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production

```bash
# Build optimized production version
npm run build

# Preview production build
npm run preview
```
